# Система Автоматической Классификации ТРУ

Данная модель автоматически классифицирует наименования 
товаров, работ и услуг (ТРУ) на основе методов обработки естественного языка (NLP) и машинного обучения. Проект разработан для ускорения и автоматизации
процесса категоризации в государственных и коммерческих закупках.
Система поддерживает масштабирование на большие объёмы данных и включает
очистку текста, векторизацию текста (TF-IDF) и ML-классификаторы.

В данной реализации представлена минимальная реализация на классических методах машинного обучения, 
исключая любые сложные системы, включая векторизацию текста через BERT или LLM структуру для дальнейшей классификации

Код реализован в качестве заметки notebook .ipynb

## Функциональные возможности (Features)
- Парсинг csv файла для обучения
- Очистка и нормализация текстов наименований ТРУ
- Автоматическое выявление и удаление кодов, артикулов, числовых последовательностей
- Генерация эмбедингов для векторизации текста (Sentence Transformers)
- Кластеризация и обучение модели классификации
- Поддержка любых категорий, включая новые
- Построение карты классификации

## Структура проекта
На данном этапе разработки код разбит на 6 блоков:
1. **Загрузка датасета**. Загружает исходный CSV или уже подготовленный data_KNN.csv. Проверяет структуру, подготавливает основной DataFrame для дальнейшей обработк
2. **Очистка и нормализация текста.** Удаляет артикулы, коды, спецсимволы, CamelCase, лишние цифры; нормализует текст и оставляет только осмысленные слова. Создаёт столбец clean.
3. **Обучение модели (TF-IDF → SVD → KMeans).** Строит TF-IDF матрицу, уменьшает размерность до 200 признаков через SVD, обучает кластеризацию MiniBatchKMeans на 80 классов. Сохраняет модели и эмбеддинги.
4. **Классификация нового текста.** Векторизует новый текст, определяет ближайший кластер, ищет примеры похожих товаров и вычисляет близость cosine similarity. Поддерживает топ-N кластеров и аномальность.
5. **Визуализация кластеров.** Строит UMAP-проекцию 50 000 товаров в 2D, сохраняет интерактивный HTML-график. Также визуализирует центры кластеров через PCA.
6. **Дообучение модели новыми классами.** Добавляет новые товары, рассчитывает их эмбеддинги, формирует новый кластер, обновляет центры KMeans и сохраняет обновлённые данные и модель.

## Дальнейшие направления исследования

1. **Улучшение качества текстовой нормализации.** В текущей версии использовалась собственная система очистки текста, однако дальнейшие улучшения могут включать:
   - подключение morphological lemmatization для русского языка (pymorphy2, Natasha, SpaCy)
   - использование частеречной разметки (POS-tagging), чтобы отделять существительные от кодов, брендов и мусорных токенов
   - расширение словаря сокращений («взр», «жен», «муж», «мм», «см» и т.д.)
   - автоматическое выявление и нормализация нестандартных товарных кодов
   - обучение кастомного правила для извлечения артикулов без потери информации

       Это позволит уменьшить шум в TF-IDF матрице и повысить качество кластеризации.

2. **Замена TF-IDF на нейросетевые эмбеддинги** Несмотря на хорошую производительность TF-IDF + SVD, современные модели позволяют добиться существенного повышения семантического качества:

   - Sentence-BERT (SBERT)
   RuBERT / RuELECTRA / RuGPT embeddings
   - fastText subword embeddings
   - GloVe адаптированный под доменные тексты

    Использование нейросетевых векторизаций позволит:
   - лучше распознавать семантические связи
   - объединять товары с разными формулировками описаний
   - устойчивее работать с короткими и неполными текстами

    Недостаток — повышенные требования к GPU, однако возможен постепенный переход.

3. **Исследование других алгоритмов кластеризации.**
KMeans выбран из-за простоты и скорости, но дальнейшее исследование может включать:
HDBSCAN (выявление шумов и плотностных структур)
   - Gaussian Mixture Models (GMM)
   - Spectral Clustering
   - Hierarchical Agglomerative Clustering 
   - KMeans++ с оптимизацией k через silhouette/knee-point search

4. **Автоматизация подбора оптимального количества кластеров.** В текущем проекте число кластеров (k=80) выбрано вручную.
В будущем можно исследовать:
   - метод “elbow” 
   - silhouette-score curve 
   - gap statistic 
   - комбинированный критерий CH + DBI 
   - автоматическое определение k через Bayesian Information Criterion (BIC)

   Это обеспечит более устойчивое разбиение.
